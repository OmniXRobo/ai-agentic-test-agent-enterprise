SkyGuard Adaptive AI Agent: Options

checking

Local companion

The extension talks only to the SkyGuard companion on this PC (127.0.0.1). It does not use any cloud service.

Pair with the companion

Open the Start menu entry SkyGuard Agent - Pairing code (or run SkyGuardAgent.cmd pair) and type the 8-digit code. It is valid for 10 minutes and works once.

Learning

Use your applications as usual. In tabs of a registered application whose access you granted, the agent notes what you click, choose and type and what the page shows, and works out the screens, tasks, statuses, business rules and roles itself (see Understanding in the side panel). Passwords and one-time codes are never captured; other websites are never observed; the agent's own actions are never learned. Everything stays on this PC.

Typing

Needs the optional "debugger" permission; the browser shows a notice while it is used. Without it the agent pauses and you type the value yourself. Values are never assigned to fields directly.

Microphone

Voice is optional. Recording happens only between Speak and Stop, and audio goes only to the local speech recognizer.
