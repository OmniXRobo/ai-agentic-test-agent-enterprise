# Root cause analysis: what 23.13.1 changes and why

| Reported or requested | What was found in 23.13.0 | Cause | Change in 23.13.1 |
|---|---|---|---|
| `INSTALL_SPEECH_MODEL.cmd` is named in the Voice hint but is not in the package | The office PC had no such file; the model had to be copied by hand. | The hint was written for a helper that was never added to the patch's application files (`ROOT_FILES`). | `INSTALL_SPEECH_MODEL.cmd` / `.ps1` and `GET_FASTER_WHISPER_MODEL.ps1` are application files now; the installer test checks that they are present. |
| The model installed as `small.ar` | Arabic recognition worked only because the model was chosen by hand. | Only the standard multilingual names (small, base ...) counted as multilingual when choosing a model for Arabic. | Any installed model without `.en` counts as multilingual for Arabic and "auto". |
| "Add the Arabic voice reply" (office PC has David, Zira, Mark only) | Arabic replies were read by the English voice, or not spoken. | Only Windows Arabic voices were considered, and the Arabic language pack cannot be downloaded offline. Language-pack voices are OneCore voices that System.Speech cannot see. | Offline Piper voice (Kareem) installed with `GET_ARABIC_VOICE.ps1` + `INSTALL_ARABIC_VOICE.cmd`; Arabic OneCore voices are listed and spoken through Windows.Media.SpeechSynthesis; an English voice never reads Arabic. |
| "Reply in Arabic voice, male and female, as chosen" | One voice for Arabic, of the radio voice's gender. | No setting; and Piper has no female Arabic voice. | *Arabic reply voice* setting (like the radio voice / Male / Female). Female: Windows Hoda, or a female Piper model, or Kareem at a higher pitch. |
| "كابدان افتا صفا" (Captain, open page) marked UNCLEAR | The wake name was not removed and the words were not translated. | The wake name was matched in Latin letters only, and the word list held the exact spellings only. The dashboard's wake listening removed all Arabic letters before matching. | The name is matched by its consonants in Arabic and Latin spellings (runtime and dashboard); misheard spellings of common command words are in the word list. |
| Arabic command answered in English when the local AI is off | The reply text could not be translated. | Reply translation needs the local AI. | A short Arabic status line is spoken; details stay on screen. |
